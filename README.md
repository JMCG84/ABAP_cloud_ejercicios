# ABAP Cloud - Ejercicios de Aprendizaje 

Este repositorio contiene los ejercicios y retos de código desarrollados durante el **Curso de Experto en SAP ABAP Cloud**. El objetivo principal es documentar mi progreso en el aprendizaje de la programación orientada a objetos (POO) dentro del entorno ABAP moderno.

##  Descripción del Proyecto
El repositorio está estructurado por clases y programas de consola que ponen en práctica conceptos clave de **ABAP Cloud** y **RESTful ABAP Programming Model (RAP)**.

### Conceptos Aplicados:
* **Programación Orientada a Objetos (POO):** Creación de clases, definición de atributos privados y métodos públicos.
* **Sintaxis Moderna:** Uso de inline declarations (`DATA(...)`), constructores (`NEW`), y String Templates (`|...|`).
* **Interfaz de Consola:** Implementación de la interfaz `if_oo_adt_classrun` para ejecutar lógica directamente en Eclipse ADT.
* **Manejo de Lógica:** Ejercicios prácticos como calculadoras con control de errores y gestión de objetos (ejemplo: Cuadros/Arte).
